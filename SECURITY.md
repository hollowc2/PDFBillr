# Security Policy

## Supported versions

Security fixes are applied to the latest commit on `main`. This is a portfolio
project and does not provide support for historical releases.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use this
repository's private vulnerability-reporting option when available, or contact
the maintainer through their GitHub profile with a concise description and
reproduction steps.

Do not include credentials, shared invoice URLs, reset links, customer data, or
other bearer tokens in a report. Acknowledgement is targeted within seven days;
the response and remediation timeline depends on severity and reproducibility.

## Scope

Reports are especially helpful for authentication and authorization, public
document links, Stripe webhooks, uploads, PDF rendering, background jobs, and
deployment configuration.
